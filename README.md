# AI 实时陪读

一个支持摄像头识别和屏幕共享识别的中文网页陪读程序。

## 识别方式

- **摄像头识别**：将实体书、绘本、试卷或题目对准摄像头。
- **共享屏幕识别**：共享桌面、浏览器窗口或应用窗口中的电子书、网页和学习材料。
- 页面稳定后可自动识别，也可以手动点击“识别”。

## 功能

- 识别文字、插图、公式和题目
- 支持绘本、故事、小说、科普、教材和解题模式
- 支持中文语音提问和浏览器语音朗读
- 保留最近阅读上下文
- 对识别不完整的信息主动提示补拍或重新共享

## 本地运行

```bash
npm install
export OPENAI_API_KEY="你的密钥"
npm run dev
```

打开 `http://localhost:3000`，允许摄像头权限；共享屏幕时请选择浏览器支持的窗口或标签页。

## 部署

在部署平台设置环境变量：

```text
OPENAI_API_KEY=你的密钥
```

摄像头和屏幕共享通常要求使用 HTTPS。

## 菜单与界面语言

界面菜单、状态提示、识别结果和操作说明均使用中文。

## 安全说明

不要把 API 密钥提交到前端代码或公开仓库。密钥应只放在服务端环境变量中。
