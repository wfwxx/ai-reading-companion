# AI Reading Companion

一个支持实时摄像头识别书页、语音提问和 AI 陪读的 Web MVP。

## 功能

- 自动打开环境摄像头读取书页
- 页面稳定后自动识别文字、插图和公式
- 支持绘本、故事、小说、科普、教材和解题模式
- 支持浏览器语音识别和语音朗读
- 保留最近阅读上下文
- 自动识别不确定信息并提示补拍

## 本地运行

```bash
npm install
export OPENAI_API_KEY="你的密钥"
npm run dev
```

打开浏览器访问 `http://localhost:3000`，并允许摄像头和麦克风权限。

## 部署

在 Vercel 或其他部署平台设置环境变量：

```text
OPENAI_API_KEY=你的密钥
```

然后部署项目。摄像头和麦克风功能一般要求 HTTPS。

## 浏览器建议

- 桌面端建议使用 Chrome 或 Edge
- 麦克风语音识别在不同浏览器支持程度不同
- 有朗读需求时可使用浏览器自带语音合成

## 安全说明

不要把 API 密钥提交到前端代码或公开仓库。密钥应只放在服务端环境变量中。
